# Domain Docs

**Status:** Active

Single-context repository.

Before domain or implementation work, consult:

- `README.md`, `CONTEXT.md`, `AGENTS.md` (existing Active sources);
- `GLOSSARY.md` if it exists;
- relevant decisions under `docs/adr/` if present.

Missing glossary/ADR files are not errors. Do not create them upfront. The relevant Pocock domain-modeling flow may create them when actual terminology or decisions warrant it.

Use terms already established in `CONTEXT.md` and any future glossary. Surface any conflict with a relevant ADR instead of silently overriding it.
